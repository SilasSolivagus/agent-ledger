# agent-ledger

看清楚你的编码 agent 到底做了什么——**会话轨迹**和**成本账单**，Claude Code、Codex 通用。

Claude Code 和 Codex 都会把每次会话完整写在你本机上，但都没给你一个看它的地方。你只能在终端里往回滚，滚到哪算哪。这个工具把那些记录读出来，画成一次会话的完整轨迹和一张总账。

**全程只读本地文件，不上传任何内容。**

## 用

```sh
npx agent-ledger report --out ledger.html
open ledger.html
```

不需要配置，不需要 API key，不需要改你 agent 的任何设置。它读的是这两个目录：

| Agent | 位置 |
|---|---|
| Claude Code | `~/.claude/projects/**/*.jsonl` |
| Codex | `~/.codex/sessions/**/*.jsonl` |

其他命令：

```sh
agent-ledger sessions            # 列出能看到的会话
agent-ledger report --limit 10   # 只看最近 10 个
```

## 看到什么

**一张总账**——固定负载、缓存命中率、首 token 中位数、累计输入输出、步数、工具调用次数。

**每次会话的轨迹**——一根发丝线是一步，圆点大小是这一步的耗时，方块是工具调用。一眼能看出工作集中在哪一段，不用读任何数字。

**逐条事件账本**——你说了什么、模型做了什么、调了哪个工具、拿到什么结果，按轮次分段。你说的话有黑色标记，工具调用有土黄标记，模型的思考退到灰色——**几百行里眼睛知道往哪落**。

生成的页面**完全自包含**：没有脚本、没有字体 CDN、没有远程样式表。断网双击照样打开。

## 一个必须知道的事

**生成的 HTML 里有你的真实工作内容**——命令、文件路径、对话原文、模型的思考。

本地自己看没问题，**但不要随手发给别人或传到网上**。本仓库的 `.gitignore` 已经排除了 `examples/*.html`，就是为了防止误提交。

（脱敏分享模式还没做，见下方待办。）

## 图表的一条规矩

每个标记代表一个明确的单位，**单位印在图上**（`一格 = 2,500 TOKEN · 每五格一个点`）。你可以数格子自己验算。

一根你没法核对的柱子只是一块颜色。

颜色只用来区分**类别**（谁说的话），从不用来表示**数量**——数量一律用长度和明度表达。

## 现在还缺什么

诚实清单：

- **Codex 的账本是空的**。数字（步数、token、工具调用）已经能读，但逐条事件还没做——它的记录结构和 Claude Code 不同。
- **没有常驻服务**。现在每次看都要重新生成一次文件。`agent-ledger serve` 还没做。
- **没有筛选和搜索**。会话多了以后不好找。
- **没有脱敏模式**。所以现在不能安全地把报告分享出去。
- **固定负载需要代理才能测到**。会话记录里不含请求信封（system prompt + 工具 schema），所以「每次请求固定携带多少」这个数字需要 `agent-ledger record` 走一次代理才有。**注意：Claude Code 的订阅登录态（OAuth）不允许走自定义 base URL，会被服务端拒绝**，这条路只对 API key 用户可用。

## 开发

```sh
pnpm install && pnpm run check   # 构建 + 14 个测试
```

代理相关的测试是重点：它站在人和他们付费使用的模型之间，所以「字节原样透传」「我们的 bug 绝不能变成用户的报错」必须被验证，而不是写在注释里。
